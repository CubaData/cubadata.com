# Cubadata Static Site

Static Astro site for Cubadata with React components and per-route SEO metadata.

## Requirements

- Node.js 22.12 or newer is recommended for Astro.
- npm is used as the package manager.

## Commands

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

`npm run dev` starts local development, usually at `http://localhost:4321`.

`npm run build` validates and generates the production site into `dist/`.

`npm run preview` serves the production build locally.

## Structure

- `src/pages/*.astro`: static routes generated by Astro.
- `src/pages/item/[slug].astro`: generates one HTML page for each post in `src/data.ts`.
- `src/layouts/BaseLayout.astro`: shared HTML document, header/footer, SEO tags, Open Graph tags, Twitter tags, and JSON-LD.
- `src/page-components`: React page body components reused by Astro routes.
- `src/components`: reusable React UI components.
- `src/data.ts`: static posts, media links, and people data.
- `src/App.css`: site-level component styles.
- `src/index.css`: global font, reset, and base styles.
- `public/images`: static images referenced by `/images/...` paths.

## SEO

The build creates real HTML files per route, including each post page. SEO metadata is set in the Astro route files and shared layout. The build also generates `sitemap-index.xml` and includes `robots.txt`.

## Adding Content

Most content lives in `src/data.ts`.

To add a new post, add a new object to the `posts` array:

```ts
{
  slug: 'mi-nuevo-post',
  title: 'Mi nuevo post',
  category: 'encuestas',
  date: '27 de abril de 2026',
  excerpt: 'Resumen corto...',
  image: '/images/post/mi-nuevo-post.jpg',
  cover: '/images/post/mi-nuevo-post-cover.jpg',
  body: ['Primer párrafo...', 'Segundo párrafo...'],
}
```

The route `/item/mi-nuevo-post` is generated automatically during `npm run build`.

## Deployment

Deploy the contents of `dist/` to any static host.

Important generated files include:

- `index.html`
- `encuestas/index.html`
- `estudios/index.html`
- `quienes-somos/index.html`
- `item/*/index.html`
- `sitemap-index.xml`
- `robots.txt`
- `_astro/`
- `images/`
